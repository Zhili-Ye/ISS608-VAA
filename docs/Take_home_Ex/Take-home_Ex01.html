Third,drop columns with high missing rates.Living Conditions(LHO1-4, LCRE, LSAV, LWDA) give me 22%-90% missing value so I will drop this section. Nearly 30% data are missing in PPO1 and PPO2 so I will also drop theses two variables.

df <- raw_data %>% select(-LHO1, -LHO2, -LHO3, -LHO4, -LCRE, -LSAV, -LWDA, -PPO1, -PPO2)

Forth, some variables needed data type conversion for subsequent data analysis. Four variables were primarily converted:

  1. CGEN (Gender): The original data consisted of text “1” and “2” instead of numbers, so it was converted to numeric.

  2. ARO4 (Better living conditions in rural areas): A backtick caused the entire column to become character data. na_if() converts empty strings and backticks to NA, and as.numeric() converts the remaining “1”, “2”, and “3” from text to numbers.

  3. ARO2 (Increased Woman roles in their families): One record had a value of 11. Normally, there are only three options: 1, 2, and 3, so this was deleted as an outlier.

  4. TOIN (Other Income): Income cannot be negative, so this was also deleted as an outlier.

df <- df %>%
  mutate(
    CGEN = as.numeric(CGEN),
    ARO4 = as.numeric(na_if(na_if(ARO4, ""), "`"))) %>%
    filter(ARO2 != 11 | is.na(ARO2)) %>%             
    filter(TOIN >= 0 | is.na(TOIN))

eth_data <- df_clean %>%
  count(Province, Race) %>%
  group_by(Province) %>%
  mutate(Total = sum(n), Pct = n / Total * 100,

ggplot(eth_data, aes(x = Province, y = Pct, fill = Race)) +
  geom_col(position = "stack", width = 0.65) +
